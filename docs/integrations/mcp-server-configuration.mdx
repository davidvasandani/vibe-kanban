## Overview

MCP servers provide additional functionality to coding agents through standardized protocols. You can define a logical MCP server once in Vibe Kanban and assign it to one or more compatible coding agents.

## Accessing MCP Server Configuration

1. Navigate to **Settings** in the Vibe Kanban interface
2. Click on **MCP Servers** in the settings sidebar
3. Add or edit a logical MCP server
4. Select the compatible coding agents that should receive that server

## Adding Custom MCP Servers

You can also add your own MCP servers by configuring them manually:

<Steps>
<Step title="Create the logical server">
Click **Add server**, enter the server name, and choose the transport configuration.
</Step>

<Step title="Choose assignments">
Select one or more compatible agents. Vibe Kanban writes the server into each selected agent's native MCP configuration file.

Example stdio server:
```json
{
  "command": "node",
  "args": ["/path/to/my-server.js"]
}
```
</Step>

<Step title="Save and Test">
After updating the JSON configuration:

1. Click **Save** to apply changes
2. Click **Test connection** to test saved native entries
3. Review test results per server and per assigned agent

<Check>
These changes update the global configuration file for each assigned coding agent and persist even if you stop using Vibe Kanban.
</Check>
</Step>
</Steps>

## Conflicts and compatibility

## Shared authentication gateway

For an OAuth-protected HTTP MCP server, run **Test connection** and choose
**Connect** when authentication is required. Vibe Kanban completes OAuth once,
encrypts the upstream access and refresh tokens locally, and writes a protected
loopback gateway URL to every matching assigned agent. Upstream credentials are
never copied into agent-native configuration.

Use the authentication badge to distinguish shared gateway, agent-native,
explicit-header, and unauthenticated modes. **Reconnect** rotates the shared
connection; **Disconnect** makes it unavailable to all assignments. Removing a
single assignment leaves remaining assignments connected. Test results report
the gateway and upstream boundaries separately.

For a server behind Cloudflare Access, an interactive HTTP redirect during OAuth
discovery produces service-token guidance. The optional Access client ID and
secret are write-only and centrally encrypted.

If Vibe Kanban finds same-name native entries with different definitions, it shows
a conflict instead of choosing one silently. Rename or delete one of the entries
before saving shared changes.

Some agents support fewer MCP transports than others. Vibe Kanban blocks an
assignment when the transport cannot be represented safely in that agent's
native configuration.

## Best Practices

<Tip>
**Server Selection**: Choose MCP servers that complement your coding agent's primary function. For example, use Playwright for agents focused on web development.
</Tip>

<Tip>
**Limit MCP Servers**: Avoid adding too many MCP servers to a single coding agent. Too many servers and tools will degrade the effectiveness of coding agents by overwhelming them with options.
</Tip>
