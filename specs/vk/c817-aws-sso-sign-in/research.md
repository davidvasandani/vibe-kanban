# Research
The catalog knowledge page separates machine installation from worker reachability. `prepare_scoped_home` symlinks non-config siblings, so a pre-created `.aws` link preserves future login and cache updates. Worker service HOME is `/var/lib/vibe-kanban`; coordinator home is the deployment dataDir. Both already access sharedRoot with aligned identities. Settings uses the coordinator AWS CLI with HOME-based SSO cache lookup. AWS_CONFIG_FILE alone cannot relocate that cache; sharing the standard `.aws` tree avoids SDK-specific configuration. Source inspection establishes these contracts; live deployment is a separate validation step.
