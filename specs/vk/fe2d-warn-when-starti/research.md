# Research

Existing `ProjectProvider` subscribes to project workspace and PR shapes. Create mode can exist outside that provider, so the advisory subscribes directly to these cached shapes for its linked project. Local `SidebarWorkspace` provides branch and execution activity, and project `Workspace` includes archive/issue/owner identity. `PullRequest.workspace_id` identifies the remote workspace, not the local ID. `CollapsibleSectionHeader.headerExtra` provides passive visibility without new section state. No new dependencies, endpoint or schema needed.
