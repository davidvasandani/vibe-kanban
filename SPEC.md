# Remember Filter Settings

Persist board filter and sorting choices when navigating or reloading. Provide actions in the Filters dialog to save a site-wide default and a personal default. Personal defaults take precedence over site defaults; remembered view choices take precedence over both. Include priority, assignee, tags, sorting, sub-issues, workspaces and blocked visibility. Search text is transient and excluded from defaults. Scope project-specific identifiers safely; keep user preferences isolated. Use existing authenticated persistence and permission boundaries for shared changes, with visible save errors and reset-to-default behavior. Verify persistence, precedence, user isolation, and both frontend consumers. Limit changes to Vibe Kanban.

Final design: remembered choices are browser-local and keyed by host, user, project and Team/Personal view. Explicit defaults use dedicated server scratch records in the self-hosted app. The cloud frontend labels its personal defaults as browser-only and hides site-wide actions. Search is separate transient state, so typing never pins inherited defaults.
